# Работа со шлюзом

`make up` создаёт базу, применяет миграции, выполняет seed и запускает API вместе с двумя эмуляторами. Порты 8180–8182 слушают только loopback. `make test` использует отдельную базу `relaylm_test`; runtime не содержит pytest и Ruff. Локальные JWT-секрет и demo-пароль можно заменить перед отдельным развёртыванием.

## Пример запроса

После входа через `/auth/login` сохранить `access_token` в переменной `TOKEN` и выполнить:

```bash
curl -N http://localhost:8180/v1/generations   -H "Authorization: Bearer $TOKEN"   -H 'Content-Type: application/json'   -H 'Idempotency-Key: example-001'   -d '{"messages":[{"role":"user","content":"Объясни идемпотентность"}],"max_tokens":64,"stream":true}'
```

Для обычного JSON указать `stream: false`. Повторный успешный запрос с тем же телом и ключом возвращает сохранённый ответ. Изменённое тело, выполняющаяся или неуспешно завершённая генерация с тем же ключом дают 409. Ключ действует внутри пользователя. Срок удаления ключей пока не задан: очистка истории должна учитывать желаемое окно повторов.

Максимум 16 сообщений, 8000 символов в одном, 16 KiB суммарного UTF-8 текста, 1024 выходных токена. Последнее сообщение — `user`, `system` допустим только первым. Одновременно допускаются три генерации пользователя, в минутном окне — 30 запросов. Отказ по бюджету — 402, лимит частоты или параллелизма — 429. Повтор сохранённого результата не расходует новую квоту.

## Проверки сбоев

`make smoke` создаёт отдельного пользователя, включает 429 у primary и проверяет backup; затем обрывает клиентский поток и проверяет закрытие upstream, освобождение резерва и отказ 402 при исчерпанном бюджете. Режимы эмуляторов возвращаются в `normal` в `finally`.

`make recovery` убивает API после первого фрагмента. После перезапуска нужно дождаться 90 секунд от приёма запроса: reaper переведёт его в `abandoned`. История должна содержать одну начатую попытку, её консервативный расход и нулевой остаток резерва. Повтор с тем же ключом не запускает модель второй раз.

```bash
docker compose ps
docker compose logs --tail=100 api
docker compose exec -T api python scripts/seed.py
```

`GET /providers` доступен demo-администратору: показывает конфигурацию без ключей и состояние circuit. Три ошибки открывают circuit на 10 секунд. Общий timeout — 20 секунд, ожидание очередного upstream-фрагмента — 3 секунды. Если процесс остановился, только возвращение API запускает reaper; отдельного сервиса восстановления нет.

`/health` проверяет PostgreSQL, `/metrics` содержит HTTP-метрики. Seed не сбрасывает существующий расход. `docker compose down` сохраняет volume. Восстановление из резервной копии, retention журнала, распределённые трассировки и интеграция с денежным биллингом не входят в эту версию.
